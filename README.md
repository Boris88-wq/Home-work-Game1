# Документация к игре "Руны Судьбы"

## Обзор
"Руны Судьбы" - это текстовая приключенческая игра, где игрок исследует магический лес, чтобы восстановить древний алтарь. Игра включает управление ресурсами (здоровье, энергия, магия и зелья) и несколько путей для завершения квеста.

## Как запустить
1. Скомпилируйте Java-файл:  
   `Game.java`

2. Запустите игру:  
   `java Game`

## Игровая механика

### Ресурсы:
- **Здоровье**: Уменьшается при ранениях, восстанавливается зельями (+5)
- **Энергия**: Требуется для действий, можно восстановить отдыхом
- **Магия**: Используется для особых способностей
- **Зелья**: Восстанавливают здоровье при использовании

### Ключевые локации:
- **Лагерь**: Начальная точка, где можно найти предметы и восстановиться
- **Лес**: Опасная зона с несколькими путями
- **Алтарь**: Место, где спрятана первая руна
- **Финальный портал**: Финал игры, требующий достаточных ресурсов

### Условие победы:
- Найти хотя бы одну руну
- Иметь минимум 5 здоровья, 3 энергии и 1 магии
- Активировать финальный портал

## Советы игрокам
- Тщательно исследуйте лагерь вначале для сбора ресурсов
- Экономно управляйте ресурсами - некоторые пути безопаснее других
- Возвращайтесь в лагерь для восстановления при необходимости
- Скрытый путь обычно самый безопасный, если вы сможете его найти
- Вам нужно будет балансировать между риском и наградой при выборе действий

## Примечания по реализации
- Игра использует паттерн "машина состояний" с разными методами для каждой локации
- Проверка ввода гарантирует, что игроки не могут сделать недопустимый выбор
- Проверка ресурсов предотвращает невозможные действия
- Игра автоматически проверяет условия завершения после каждого действия

Эта реализация соответствует всем требованиям из описания проекта, включая управление ресурсами, несколько путей прохождения, обработку ошибок и полный игровой цикл.
